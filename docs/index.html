为什么需要它

下载一个安装包，不该这么麻烦

从搜索到落盘，中间每一步都在消耗你的时间。这个工具把整件事收进一个终端窗口。

只记得名字，不记得作者

打开 GitHub 搜半天，翻遍搜索结果才能找到正确的仓库？这里只输仓库名关键词，按星标排好候选，输入编号即可。

Release 页面手动翻找

资产列表一长串，还得自己分辨 ZIP、EXE、MSI、DMG。工具按扩展名筛好，最近的版本一次列全。

下载到一半断流重来

浏览器下载不好管理，命令行参数又记不住。流式下载带实时进度，中断自动清理残文件，全程只按数字。

现在，搜索 → 选择 → 下载 三步完成，收藏夹还会记住你常用的仓库。

核心功能

为「找得到、下得稳」而设计

不堆砌功能，每一个都对应一个真实的下载痛点。

按名字搜索，无需作者

GitHub Search API 按星标排序返回候选仓库，展示作者、语言、星标与简介，输编号就能进 Release 资产页。

收藏夹持久化

常用的「作者/仓库」存进 favorites.json，记下简介、星标与资产清单，重启后依然在，大小写不同也不重复。

多线程高速下载

流式落盘配合实时进度条，显示百分比、速度与剩余时间；先写 .part 校验后再改名，不留半截文件。

按类型智能筛选

先问 ZIP 还是 EXE，MSI、DMG、DEB、AppImage 等按资产里实际出现的类型动态列出，最后一项永远是「全部」。

一键解除 API 限流

菜单按 0 直达 GitHub 官方 Token 创建页，粘贴回来只写本地 .github_token，限额从 60 次/小时提升到 5000 次。

终端友好，报错清晰

表格自适应列宽，中英文不错位；限流、超时、代理 SSL、仓库不存在都给可读提示，异常写入 crash.log 不再一闪而过。

三种下载方式

同一个文件，三种拿法

选完资产后按习惯来：直接下到本地、交给浏览器，或者只拿链接。

01

直接下载

用 requests 把文件流式写到本地磁盘，程序内完成整个下载过程。

  • 实时进度条：百分比、速度、剩余时间
  • .part 临时文件校验通过后才改名
  • 同名自动加 (1)、(2)，不覆盖旧文件
选中资产 → 直接下载 → 选目录
02

浏览器下载

调用系统默认浏览器打开资产链接，用你熟悉的浏览器管理器接管下载。

  • 一条命令唤起默认浏览器
  • 沿用浏览器里的下载规则与限速设置
  • 也可以只开浏览器、不在本地落盘
选中资产 → 浏览器下载
03

复制链接下载

不发起下载，只把资产链接打印出来，粘到任何你惯用的下载工具里。

  • 命令行模式一条语句列出全部链接
  • 支持按扩展名筛选、查看历史 Release
  • 适合 Aria2、IDM 或远程协作排障
python cli.py owner/repo
下载路径配置

下到哪里，你说了算

每次下载前都可以重新选择保存位置，默认目录、临时目录、永久记住四种方式覆盖所有场景。

1使用当前默认目录直接沿用现有默认位置，选项里会显示完整路径
2换一个位置（仅本次）这次下到别处，不改变任何默认设置
3换一个位置并记住写入 config.json，以后默认就指向它
4恢复系统默认下载目录设置过默认目录后出现，一键撤销
路径支持 ~ 家目录与相对路径，不存在的目录自动创建；创建失败会回退并说明原因，不打断下载。
下载目录优先级
# 由高到低，先命中先使用 环境变量 GHR_DOWNLOAD_DIR 配置文件 config.json → download_dir 系统默认 ~/Downloads # Windows 临时改一次 set GHR_DOWNLOAD_DIR=D:\Downloads # PowerShell $env:GHR_DOWNLOAD_DIR="D:\Downloads" # Linux / macOS export GHR_DOWNLOAD_DIR=~/Downloads
